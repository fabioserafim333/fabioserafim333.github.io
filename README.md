# 👟 UrbanStep

E-commerce fictício de tênis desenvolvido com **HTML, CSS e JavaScript**, simulando uma loja online com catálogo de produtos, filtros e carrinho de compras.

## 🚀 Funcionalidades

- 🛍️ Catálogo de tênis
- 🔎 Busca por produtos
- 🏷️ Filtro por categoria
- 🛒 Carrinho de compras
- ➕ Alteração da quantidade de produtos
- 🗑️ Remoção de produtos do carrinho
- 💰 Cálculo automático do total
- 💾 Persistência do carrinho utilizando `localStorage`
- 📱 Layout responsivo
- 💳 Simulação de finalização da compra

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📂 Estrutura do projeto

```text
urbanstep-ecommerce/
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ Como executar

Não é necessário instalar nenhuma dependência.

Basta baixar ou clonar o projeto e abrir o arquivo:

```text
index.html
```

em um navegador.

## 🎯 Objetivo

Projeto desenvolvido para praticar conceitos de desenvolvimento web, incluindo:

- Estruturação de páginas com HTML
- Estilização e responsividade com CSS
- Manipulação do DOM com JavaScript
- Eventos e interações com o usuário
- Arrays e objetos em JavaScript
- Persistência de dados com `localStorage`
